# Frank Privacy Policy

Public privacy policy page for the Frank app.

## Updating

1. Edit `index.html` with your changes
2. Commit and push to `main`
3. GitHub Pages will auto-deploy within 1-3 minutes

## Custom Domain (Optional)

To use a custom domain (e.g., frank-app.net):

1. Purchase your domain
2. At your DNS provider, add a CNAME record: `www` -> `Phatts3262.github.io`
3. For apex domain, add A records:
   - 185.199.108.153
   - 185.199.109.153
   - 185.199.110.153
   - 185.199.111.153
4. In this repo: Settings > Pages > Custom domain, enter your domain
5. Check "Enforce HTTPS" (certificate may take up to 24 hours)
