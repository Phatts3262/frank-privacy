# Frank - Landing Page and Privacy Policy

Public website for the Frank app.

## Structure

- `index.html` -- Landing page (https://phatts3262.github.io/frank-privacy/)
- `privacy.html` -- Privacy policy (https://phatts3262.github.io/frank-privacy/privacy.html)
- `terms.html` -- Terms of service (https://phatts3262.github.io/frank-privacy/terms.html)
- `legal.css` -- Shared dark brand stylesheet for privacy.html and terms.html
- `assets/` -- Images and icons

## Updating

1. Edit the HTML files
2. Commit and push to `main`
3. GitHub Pages auto-deploys within 1-3 minutes

## Custom Domain (Optional)

To use a custom domain (e.g., frank-app.net):

1. At your DNS provider, add a CNAME record: `www` -> `phatts3262.github.io`
2. For apex domain, add A records:
   - 185.199.108.153
   - 185.199.109.153
   - 185.199.110.153
   - 185.199.111.153
3. In this repo: Settings > Pages > Custom domain > enter your domain
4. Check "Enforce HTTPS"
